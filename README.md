Quish Sonyar is a Flutter-based QR code scanner designed to help detect potential quishing (QR phishing) threats before users open links. It analyzes QR content using URL normalization, suspicious pattern detection, and preliminary risk classification, providing clear security findings without automatically visiting websites.
